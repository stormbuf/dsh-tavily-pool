# dsh-tavily-pool 使用说明

[English](./usage.md) | **简体中文**

用 [Tavily](https://tavily.com) 替代 DeepSeek Harness 内置的 web 搜索与网页抓取，支持多把 API 密钥、余额感知调度、失败自动切换与用量统计。

## 安装

```sh
dsh plugin add dsh-tavily-pool
```

安装后重启 DSH，打开 **设置 → 插件**，即可看到本插件的配置卡片。

## 添加密钥

本插件**不读取环境变量**，也不读取 DSH 的 credentials 服务——密钥只能在面板里手动粘贴。

1. 打开 **设置 → 插件 → dsh-tavily-pool**
2. 在密钥输入框粘贴一把 Tavily API key（形如 `tvly-...`）
3. 点保存

可添加任意多把。列表只显示脱敏形式（`tvly-...xxxx`），明文仅保存在本机：

```
~/.dsh/dsh-tavily-pool/keys.json
```

该文件权限为仅当前用户可读。本插件不提供任何返回密钥明文的接口，也不提供导入/导出功能。

## 开关

有两个**独立**开关：

| 开关 | 关闭时的行为 |
|---|---|
| **搜索接管** | 搜索请求转交 DSH 官方搜索提供方 |
| **抓取接管** | 抓取请求转交 DSH 内置的本地 HTTP 抓取器 |

两者互不影响——例如你可以只用 Tavily 搜索、同时保留内置抓取。

> ⚠️ **卡片上目前只有搜索开关。** 抓取接管仍在开发中（ticket `10`）：`fetchEnabled` 这个设置项
> 还不存在，`fetchProvider` 也仍指向内置的本地 HTTP 抓取器。在它落地之前，卡片只渲染搜索开关
> 并写明这一点——渲染一个拨了没有任何效果的开关，比不渲染更糟。

开关改动**即时生效**，无需重启。

## 搜索参数

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| **搜索深度** `searchDepth` | `basic` / `advanced` / `fast` / `ultra-fast` | `basic` | 相关性与延迟的取舍。`advanced` 每次计 **2 积分**，其余三档计 1 积分 |
| **结果数上限** `maxResults` | 1–20 | 10 | 单次搜索最多取回多少条来源 |
| **主题** `topic` | `general` / `news` / `finance` | `general` | `news` 适合时事，`finance` 适合金融 |
| **生成答案** `includeAnswer` | 开 / 关 | 关 | 让 Tavily 额外生成一段答案，作为搜索结果的正文返回 |

参数改动同样**即时生效**，下一次搜索就带上新值。

`maxResults` 是**上限**而非保证：模型调用搜索时可以要求更少，此时以它要的为准；结果最终还会由 DSH 的接缝再截断一次。下界是 1——官方接口文档写的是 0，但实测 `0` 会被上游以 `400 Invalid max results.` 拒绝，而这类错误不会重试也不会切换密钥，因此面板不接受它。

## 调度

密钥池默认按**余额优先**调度：

- 剩余额度多的先用
- 余额为「无限」的密钥最优先
- 余额**未知**的密钥垫底（未知不等于零）
- 同一额度档内轮转打散

某把密钥临时失败（限流 `429`、服务端 `5xx`）时会被**冷却**，冷却期内**不参与**密钥选择（即使池内其余密钥都不可用，也不会使用它）；冷却结束后自动恢复。

若**所有**密钥都在冷却中，插件会**等待**最早到期的那把，而不是立刻失败——但仅当那一刻落在等待预算之内。超预算时它不会傻等：等一个到不了的到期时刻只会把失败推迟，因此它会立刻返回上游的错误，并保留原始响应里的 `request_id`。

池中密钥的失败会触发**故障切换**：插件自动改用另一把。同一把密钥在一次请求里不会被重复尝试。

**额度耗尽**（`432` / `433`）与冷却不同：它不是「等一会儿」的问题，而是这把密钥在当前计费周期内没量了。这种密钥会一直**不被选中**，直到确认它恢复为止。

Tavily 的用量在**每月 1 日**归零。由于官方没有说明该重置发生在哪个时区，插件会在跨越月起始后**自动探测**：从 UTC 月起始开始，每隔 6 小时检查一次，最多持续 48 小时——这个窗口足以覆盖全球任何一个时区的月初。探测只调用余额查询接口，**不消耗积分**。

你也可以随时在面板上点「刷新余额」立刻检查。若 48 小时内始终未恢复，通常意味着需要到 [Tavily dashboard](https://app.tavily.com/account/plan) 提高限额，而不是等时间。

若池内已无可用密钥，请求会按上面的开关设置**回落**。回落有三种触发情形：搜索开关关闭、密钥池文件损坏（此时以空池继续，并在日志里报告该文件）、以及池内没有任何**可能在本次请求内**恢复的候选（空池、全部停用、全部额度耗尽或永久失效）。

> 注意「没有任何可用密钥」与「刚试过、刚失败」是两回事：后者手上有上游的真实答复，插件会把它如实上报（含 `request_id`），**不会**换一个来源重试。

回落目标自己也可能不可用，两种情形会给出**不同的错误码**，因为要用户做的事不同：

| 错误码 | 含义 | 该怎么办 |
|---|---|---|
| `TAVILY_FALLBACK_CREDENTIAL_MISSING` | 官方凭据**从未配置** | 配一把（面板的 Models 页、环境变量 `DEEPSEEK_API_KEY`，或 `web-search-deepseek` 的 `apiKey`） |
| `TAVILY_FALLBACK_CREDENTIAL_INVALID` | 官方凭据配了，但上游以 `401` / `403` 拒绝 | 换一把，而不是再配一次 |

两条错误都会带上「为什么离开 Tavily」，因为只看到一条关于 DeepSeek 凭据的错误，会让人去修错的东西。

密钥失败分为三类：

- **永久失效**（如响应体明确指示密钥被吊销或无效）——需要你处理
- **临时失败**（限流、服务端错误）——冷却后自动恢复
- **额度耗尽**（`432` / `433`）——只在确认余额回升后才恢复；可到 [Tavily dashboard](https://app.tavily.com/account/plan) 提高限额

> 本插件**无法得知**两把密钥是否属于同一个账号（官方 API 不提供归属信息），因此不区分「账号级」与「密钥级」故障，一律按**单把密钥**处理。

## 余额刷新

面板上的「刷新余额」按钮会调用 Tavily 的 `/usage` 接口拉取官方余额。

Tavily 对该接口限流为 **10 次 / 10 分钟**，因此本插件对每把密钥做了配额预占，不会触发限流。刷新失败时**保留旧值并标记为陈旧**，不会用 0 覆盖。

本插件**不推测计费周期**——余额一律以官方 `/usage` 返回的当前周期数值为准。

## 计费口径

- **搜索**：`basic` / `fast` / `ultra-fast` 为 1 积分，`advanced` 为 2 积分
- **抓取**：每 **5 个成功抓取**的 URL 计 1 积分（`basic`）或 2 积分（`advanced`）；失败的 URL **不计费**

因此单次抓取常见消耗为 0 积分。

## 手动回退

若插件加载失败导致搜索不可用，DSH 会报 `WEB_PROVIDER_CONFIGURED_MISSING`。此时把 profile patch 里的提供方改回官方值即可恢复。

编辑：

```
~/.dsh/profiles/<profile>/cordis.patch.yml
```

找到覆盖 `web` 行的那一段，把 `searchProvider` 与 `fetchProvider` 改回官方值：

```yaml
- id: web
  config:
    searchProvider: deepseek-official
    fetchProvider: http
```

> ⚠️ **两个字段必须同时写全。** patch 的 `config` 是**整体替换**而非合并；只写一个会让另一个字段变为「未配置」，从而走自动选择——这不会报错，但行为不再是你要的。

保存即可生效，无需重启（profile 的 `patchReload` 为 `live`）。

改完后可以停用或移除本插件。

## 与其它 DSH Tavily 插件的区别

DSH 生态里还有两个同主题插件，本插件与它们的定位不同：

| | `szmy-haruhi/dsh-tavily` | `@yuuz12/dsh-tavily` | **dsh-tavily-pool** |
|---|---|---|---|
| 密钥模型 | 单密钥 / 免密钥模式 | 多密钥池 | **多密钥池** |
| 余额感知调度 | 无 | 有 | **有** |
| 故障切换与冷却 | 无 | 有 | **有** |
| 用量统计 | 无 | 有 | **有** |
| 网页抓取接管 | 无 | 无 | **有** |
| 接管方式 | 静态配置固定 | 运行时改写内部字段 | **静态配置固定** |

本插件**不支持**免密钥（keyless）模式——免密钥调用无法归属到你的账号，因而无法记账，也无法显示余额。
